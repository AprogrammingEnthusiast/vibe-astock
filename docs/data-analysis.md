# 数据与分析规范

文中代码路径以仓库根目录为基准。

- 硬指标来自数据源和纯计算；AI 负责解释。行情缺失、过期或降级必须显式标注，不能用未标记的模拟数据填补；`price=0` 的无效行情不能显示成真实归零，也不能进入 AI 的盈亏结论。
- 市场日期与时间复用 `duanxian/trade_calendar.py` 和 `duanxian/util.py` 的上海时区工具。历史分析以目标交易日截断；实时行情不能冒充已错过时点的快照。
- 默认产品只做市场、板块研判和个股客观事实、风险披露。分析口径集中在 `duanxian/prompts.py`；更改结论结构时同步模型、JSON 骨架和渲染函数。新增 PromptPack 可选字段保留默认值，以兼容用户的本地包。
- 涨停样本统计保留样本偏差披露，不表述为可成交策略收益。公共复盘与深挖的输入、提示词及产物保持个人交易数据隔离。
- 保存复盘复用 `duanxian/review_store.py`：不可用的新产物不能覆盖已有可用结果。账本损坏应报错并保留原数据，不能当作空账本写回；迁移前备份。
- 取数降级复用 `duanxian/data.py` 的 `[⚠️ …]` 信封，体检、降级识别与 UI 都依赖它。`preflight.check()` 核心数据不足时拒绝调用模型，非核心缺失进入 warnings；不能把失败换成看似正常的非空文本。
- 结构化模型输出复用 `duanxian/structured.py` 的解析、Pydantic 校验和有限重试。配置错误通过 `duanxian/llm_errors.py` 上抛，不能靠反复重试或自由文本降级掩盖凭证/模型配置错误。
