# 共享账号开发规范

文中代码路径以仓库根目录为基准。

修改共享账号、邀请、凭证、账号隔离、公共发布，或部署、迁移共享网站前，先读 [SHARING.md](../SHARING.md) 对应章节；操作步骤以该文档为准。网关使用 SQLite，相关代码为 `sharing.py`、`account_context.py`、`sharing_admin.py`、`sharing_worker.py`、`sharing_schema.py`。

- 共享部署使用一个应用进程，服务端会话绑定账号上下文；个人文件、模型运行环境与任务状态按账号隔离。浏览器提交的账号编号不能成为身份依据，不挂载 Docker socket。
- 本人 HOME 固定在账号数据库同目录的 `homes/<账号ID>`；线程显式继承账号上下文，不能修改全局环境变量或回退至宿主机 HOME。
- 邀请直接创建账号，不预分配实例或名额。保留旧数据库与旧卷；迁移仅通过显式 `import-home` 从停止写入的只读旧 HOME 复制，拒绝链接和覆盖已有目标。
- 公共内容发布统一经过 `sharing_schema.public_payload()`；只共享市场分析产物。个人对话、自选、持仓、交易日志和凭证留在本人空间，发布失败保留待发送数据。
- 阅读共享结果不触发 AI；生成分析和追问使用发起者配置，缺少凭证时明确报错，不能回退到其他账号或宿主机凭证。
- 前端账号存储和请求复用 `frontend/src/lib/account.ts` 的账号键与请求封装，覆盖切换账号、退出、流式请求场景。
- `.env`、`.sharing/`、CLI 登录文件、用户数据和备份包含敏感信息，不提交或输出其内容。部署配置样例使用占位符。
